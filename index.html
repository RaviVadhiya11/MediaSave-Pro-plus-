Help center

Frequently asked questions

Why does a social-media link not work?

A post URL is a webpage, not a direct media-file URL. This static tool does not extract media from social platforms.

Why did my download fail?

The host may block cross-origin browser requests (CORS), require authentication, or provide a webpage instead of a file.

Where is my history stored?

File names and timestamps are stored in local storage on this device/browser. Clearing browser site data removes them.

Can I install this website?

Yes, on supported browsers use the browser menu or the install button when it appears. HTTPS is required.

Privacy policy

Your privacy matters.

Local data

Download history and theme preference are stored in your browser's local storage. MediaSave Pro does not send this history to a server.

Third-party file hosts

When you paste a direct URL, your browser contacts that URL's host. That host may receive your IP address and apply its own privacy policy. Review the host's terms before using it.

Cookies and analytics

This starter version does not include analytics trackers or advertising cookies. If you add third-party services later, update this policy.
